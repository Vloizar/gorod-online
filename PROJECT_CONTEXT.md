# Город онлайн — контекст проекта

## Назначение

Мобильное приложение и веб-кабинеты для проекта «Город онлайн».

## Стек

- Flutter — приложение для Android и iOS.
- Laravel — API и веб-кабинеты.
- MySQL 8.4 — основная база данных.
- Разработка ведётся на Windows.
- Финальная сборка iOS потребует macOS и Xcode.

## Структура репозитория

- `gorod_online_SDK/gorod_online/` — Flutter-приложение.
- `backend/` — Laravel API.

## Текущее состояние

- Git, VS Code, PHP 8.4, Composer, MySQL, Flutter и Android Studio установлены.
- Flutter-проект запускается через `flutter run -d chrome`.
- Laravel запускается через `php artisan serve`.
- Laravel подключён к MySQL, миграции выполнены.
- На Flutter создан экран входа по номеру телефона и паролю.
- API входа начато, но реализацию временно отложили.
- Проект и задачи ведутся в Linear: проект «Город онлайн», команда «Андрей».
- GitHub-репозиторий: https://github.com/Vloizar/gorod-online

## Принятые решения по авторизации

- Регистрация: номер телефона + пароль.
- Электронную почту не использовать.
- Восстановление: номер телефона + 4-значный код, заданный при регистрации.
- Если код или пароль забыты — кнопка «Обратиться к администратору».
- SMS-восстановление отложено на следующий этап.

## Ранее согласованные решения

- Карта экранов `gorod-map-v05` подготовлена в одном файле на одном рабочем поле.
- Для дизайна допустимы Figma или draw.io; текущая карта экранов — draw.io.
- Бесплатные ограничения Figma учитываются: до 3 командных файлов Design и 3 досок FigJam, лимиты AI и максимум 2 редактора в командном файле.
- Основной способ восстановления для первой версии — 4-значный код. При забытом коде или пароле пользователь обращается к администратору.
- Email и менеджер паролей не используются.
- SMS-восстановление будет добавлено позже.
- В Linear создан проект «Город онлайн» в команде «Андрей».
- Текущее состояние Linear: окружение разработки завершено; проверка стартовых исходников в работе; API входа отложено до следующего этапа.
