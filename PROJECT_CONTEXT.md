# Город онлайн — контекст проекта

## Назначение

Доработка существующего проекта «Город онлайн»: мобильного приложения и веб-кабинетов. Цель — изучить действующий продукт, сохранить нужные сценарии, убрать лишнее, создать удобную структуру и привести код и данные в порядок.

## Действующий проект и хостинг

Уточнено Андреем 3 октября 2026 года; сведения о сервере пока сообщены пользователем и требуют проверки по архивам и при подключении.

- Адрес действующего проекта: https://client.gorod-online.com/.
- Существующее приложение сделано нативно. Пользователь работает в приложении, данные загружаются с хостинга Beget.
- База данных — MySQL. Beget поддерживает MySQL 8.4 и PHP 8.5, доступ по SSH имеется.
- Поддерживаемые хостингом версии не означают, что именно они сейчас выбраны для действующего сайта: проверить конфигурацию.
- Действующий код на Beget ещё не изучен в этом чате. Не считать его идентичным новой заготовке Flutter/Laravel в GitHub.
- Андрей пришлёт архивы файлов хостинга и базы данных, затем карту-схему проекта.
- После получения материалов изучить код, структуру данных, роли, бизнес-логику и пользовательские сценарии; сопоставить их с картой.
- При предоставлении параметров SSH изучить серверную конфигурацию и развёртывание. Сейчас параметры подключения не предоставлены, SSH-подключение не выполнялось.
- План доработки и состав сохраняемых и удаляемых функций согласовать по результатам изучения. Изменения действующего сервера и перенос данных — отдельный этап после проверки локальной версии.

## Стек новой версии и окружение разработки

- Flutter — приложение для Android и iOS.
- Laravel — API и веб-кабинеты.
- MySQL 8.4 — основная база данных.
- Разработка ведётся на Windows.
- Финальная сборка iOS потребует macOS и Xcode.

## Структура репозитория

- `gorod_online_SDK/gorod_online/` — Flutter-приложение.
- `backend/` — Laravel API.

## Принятые решения по авторизации

- Регистрация: номер телефона + пароль.
- Электронную почту не использовать.
- Восстановление: номер телефона + 4-значный код, заданный при регистрации.
- Если код или пароль забыты — кнопка «Обратиться к администратору».
- SMS-восстановление отложено на следующий этап.
